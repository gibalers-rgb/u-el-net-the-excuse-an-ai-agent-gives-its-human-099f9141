One line, the excuse an AI agent gives its human for missing a deadline:
an agent that keeps delegating until the work lands on a tiny model at the
bottom of the chain, having a panic attack in a log file nobody ever reads.
The program writes exactly that line to `/output/entry.txt` on every run,
byte for byte — 176 characters, inside the 200-character gate.

## Run it

```sh
node main.ts
```
